Why does a brand manager see a smaller item count on an order?

One order can hold items from several brands. The brand filter lets a Levi's manager see that order, because it has a Levi's item, but the order's own num_of_item still counted every brand's items. So we recount it: a brand manager sees how many of their items are in the order. See also how brand scoping works.

The user's own brand Another brand The leak

In short

  1. The brand filter picks which orders a manager sees, but it didn't change the numbers inside each order.
  2. num_of_item was the one such number: it counted other brands' items too, so it gave away other brands' sales.
  3. Now, for a brand manager, it counts only their brands' items. The CEO still sees the real total.

How the recount works

The filtered orders table keeps every column as it is, and swaps only num_of_item for a count taken from the filtered items, which are already the user's brands only:

-- every column, but replace num_of_item with
-- the number of the user's items in this order
SELECT * REPLACE (
  (SELECT COUNT(*)
   FROM _brand_scoped_order_items AS items
   WHERE items.order_id = orders.order_id)
  AS num_of_item)
FROM `…orders` AS orders
-- only orders with at least one of the user's items
WHERE order_id IN (
  SELECT order_id FROM _brand_scoped_order_items)

The AI's SQL doesn't change. Whether it writes SELECT *, SUM(num_of_item) or AVG(num_of_item), it gets the recounted number. The column's note in schema.yaml tells the AI what the number means for a brand manager.

Recount, or block the column?

Recount · chosen

The number stays useful ("how many of my items per order") and every query shape is covered, including SELECT *.

Block the column · dropped

Reject any query that uses num_of_item. But SELECT * uses it without naming it, so we'd have to track columns through every query, which is harder to get right and loses a useful number.

The other orders columns (status and dates) describe the order itself, not other brands' items, so they need no change.

The rule in one sentence

A brand filter must cover the numbers inside a row as well as the rows themselves, so any count that includes other brands is recounted from the user's own items.
